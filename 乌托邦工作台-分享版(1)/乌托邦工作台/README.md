# 乌托邦工作台 · 分享版

橙子的个人工作台，单文件网页。里面有：待办四象限、健身记录、成长目标、内容工作台（选题/初稿/灵感抓取）、月度绩效。

> **先看完这段再动手**——一句话：
> 这个包里**没有**橙子的云库 key（已清掉）。你双击打开就是**纯本地**，数据只在你浏览器里。
> 想要跨设备同步，得**建你自己的云服务**，5 分钟，之后填进 `config.js`。

## 三种用法，按需选一个

### 用法 0：直接双击打开（零配置，先看看）

双击 `index.html`。

数据存在**你这台电脑的浏览器里**，关掉再打开还在，换电脑就没了。
顶部会出现一条「本地模式」提示条——那是正常的，意思就是"没连云、数据只在你机器上"。

### 用法 1：建自己的云服务 → 跨设备同步（推荐长期使用）

**这是你自己的库，跟橙子的完全无关。**

1. 在 WorkBuddy 里搜「云服务」，让 AI 帮你建一个应用
2. 拿到你自己的 `endpoint`（形如 `https://xxx.app.workbuddy.host`）和 `publishableKey`（形如 `wbpk_xxxxxxxx_xxxxxxxx`）
3. 打开 `config.js`，填进 `cloud.endpoint` 和 `cloud.publishableKey`，保存
4. 刷新页面，用**你自己的手机号**登录

- 你的数据只有你能看到（按账号 `owner_id` 隔离）
- 手机/电脑登同一账号 → 实时同步
- 想发布成自己的网址：接着走「用法 2」

> 注意：填别人的 `wbpk_` key 会把你数据写进别人名下。包里的 `config.js` 默认是空的，就是防止手滑。

### 用法 2：发布成自己的网址（给「会折腾」的朋友）

改完 `config.js` 之后：

1. 在 WorkBuddy 里搜「发布为应用」（或 `sites`）
2. 选这个文件夹，静态站点，入口 `index.html`
3. 拿到一个 `xxx.app.workbuddy.host` 链接

这个链接可分享，手机上打开能「添加到主屏幕」，跟 App 一样。

## 要改配置，只动一个文件

**`config.js`** —— 每项都有注释。改完保存，刷新页面生效。

`index.html` 有 900KB+，正常情况下**不需要碰**。真要改模块，搜关键词即可：

| 想改什么 | 搜这个关键词 |
|---|---|
| 待办四象限 | `q1` / `PRIO_LEVELS` / `四象限` |
| 健身记录 | `fitness` / `GOAL` |
| 成长目标 | `growth` |
| 内容工作台 | `work` / `draft` |
| 配色 / 主题 | `--accent` / `FF6D24` |
| 卜卜 / 五球 | `ART` |

## 文件说明

| 文件 | 作用 |
|---|---|
| `index.html` | 主程序（900KB+，全内联，零外链） |
| `config.js` | **配置文件，改这里**（默认全空 = 纯本地） |
| `manifest.webmanifest` | PWA 配置（桌面图标、启动方式） |
| `sw.js` | 离线缓存，让断网也能打开 |
| `icon-192.png` / `icon-512.png` | 图标 |

## 已知边界

- 默认（不填 config.js）数据不丢在 localStorage，但不跨设备
- 灵感抓取面板只显示跑批缺口，不能直接执行（需要本地 Python 环境）
- 数据导出：页面右下角有「导出 JSON 备份」
